PyLay

An iOS-inspired UI framework for pygame. PyLay provides a hierarchical widget tree, spring-based physics animations, reactive state management, and a complete iOS-style theming system — built entirely on top of pygame without any external UI toolkit.

PyLay powers the entire Pianove interface and is independently usable in any pygame application. It ships with 29 widgets, a page router with animated transitions, and a layout engine that scales to any window size.
