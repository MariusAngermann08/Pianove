PyLute

A music notation rendering library for pygame. PyLute parses MusicXML files and draws proportional, engraved sheet music on any pygame surface — clef symbols, key signatures, time signatures, beams, accidentals, and ledger lines, all using the Bravura SMuFL font.

PyLute is used inside Pianove to display the sheet music view, but it is a fully independent library that can be embedded in any pygame application.
