Making Lessons

Lesson & Course Format

Lessons and courses are folders of plain JSON: readable, diff-friendly and easy to share.

JSONOne file per languageFor contributors

Where they live

pianove/lessons/<id>/                 built-in lessons (ship with the app, read-only)
pianove/courses/<id>/                 built-in courses
~/.pianove/packages/lessons/<id>/     your lessons: made in the editor or imported
~/.pianove/packages/courses/<id>/     your courses

Both places are scanned whenever the Lessons tab is shown. A lesson in your folder with the same id as a built-in one replaces it. Progress is stored by lesson id, which is why the editor never renames a lesson and duplicates a built-in one under a new id (welcome_copy).

A lesson folder

lessons/waltz_for_mia/
  meta.json     identity, author, difficulty, tags
  en.json       title and description in English
  de.json       … in German (one file per language)
  steps.json    what the lesson does, step by step

meta.json

{
  "id": "waltz_for_mia",
  "version": "1.0.0",
  "author": "Mia",
  "difficulty": "beginner",
  "tags": ["melody", "rhythm"],
  "locales": ["en", "de"],
  "estimated_minutes": 5,
  "based_on": "simple_waltz"
}

id must match the folder name (lowercase letters, digits and _). difficulty is beginner, intermediate or advanced. based_on is written by Duplicate and optional.

en.json, de.json

{ "title": "Waltz for Mia", "description": "A gentle waltz in three-four time." }

steps.json

A list of steps, played in order. There are two types, and a lesson should end with an exercise.

scene: explaining something

A scene is a list of beats (screens) with text, the keyboard, animated hands and an optional staff. Texts are written in every language right in the beat.

{
  "type": "scene",
  "title": { "en": "The C major scale", "de": "Die C-Dur-Tonleiter" },
  "beats": [
    {
      "title":  { "en": "The thumb passes under", "de": "Der Daumen geht unten durch" },
      "say":    { "en": "Watch the thumb …", "de": "Achte auf den Daumen …" },
      "labels": ["E4", "F4"],
      "mark":   ["F4"],
      "play":   ["C4", "D4", "E4", "F4", "G4"],
      "fingers": [1, 2, 3, 1, 2],
      "tempo":  54,
      "staff":  { "clef": "treble", "notes": ["C4", "D4", "E4", "F4", "G4"] }
    }
  ]
}
FieldMeaning
title, sayHeading and text of the screen, per language
labelsKey names to show: a list of keys, or "C" (every C), "white", "hand" (keys under the fingers)
markKeys that are highlighted
playA phrase Pianove plays with the hand; an entry like "C4+E4" is a chord
fingersThe finger (1 = thumb … 5) for each entry of play; "1+3+5" for a chord
tempoBeats per minute for play (default 76)
accent, velocitiesStress every n-th note; loudness (1–127) per note
try, try_sayWhat the learner plays afterwards ("play": the same notes, or a list of notes) and the prompt shown
hand, numbers, sideWhere the fingers rest ({"right": {"C4": 1, …}}), whether finger numbers show, which hand plays
staff{"clef": "treble"/"bass"/"grand", "key": 1, "time": [3, 4], "notes": […], "under": "names"/"count"}

exercise: the piece

The music the learner plays from the staff, bar by bar: bars (notes per bar) and types (their values: quarter, eighth, half, …, with dots, triplets, rests and ties). An optional lh with its own bars and types puts the exercise on a grand staff for both hands.

The full, current reference for every field is LESSON_FORMAT.md in the repository; the easiest way to get a correct file is to make the lesson in Creator Mode and look at what it saved.

A course folder

// courses/beginner_path/meta.json
{
  "id": "beginner_path",
  "version": "2.0.0",
  "author": "Pianove",
  "difficulty": "beginner",
  "lessons": ["welcome", "c_major_scale", "five_note_melody", "…"]
}

Plus an en.json / de.json with its title and description, as for lessons.

Packages

A .pianove-pkg file is a zip with lessons/<id>/ and courses/<id>/ folders, exactly as above. Imports are checked: at most 20 MB, no paths outside those folders, valid ids and a steps.json for every lesson.
