Getting Started

Installation

A step-by-step install on Windows, macOS and Linux, in a virtual environment.

Ready-made appor from source

The ready-made app

The Releases page has Pianove for every platform, built automatically for each version. Nothing else to install: Python, the libraries and the piano sound are inside.

PlatformDownloadStart
WindowsPianove-Windows.zipUnpack, open the folder, run Pianove.exe
macOSPianove-macOS.zipUnpack, move Pianove.app to Applications; the first time, right-click it and choose Open (the app isn't signed)
LinuxPianove-Linux.tar.gztar xzf Pianove-Linux.tar.gz && ./Pianove/Pianove

The rest of this page is for running Pianove from source, for example to change it.

1. Install Python

  • Windows: get the installer from python.org and tick Add Python to PATH.
  • macOS: brew install python
  • Linux: Python 3 is usually there already; otherwise sudo apt install python3 python3-venv python3-pip (or your distribution's equivalent).
python --version   # 3.10 or newer

2. Get the source

git clone https://github.com/MariusAngermann08/Pianove.git
cd Pianove

No git? On GitHub choose Code → Download ZIP, unpack it and open a terminal in the folder.

3. Create a virtual environment

Recommended: it keeps Pianove's packages apart from the rest of your system.

python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

4. Install the dependencies

pip install -r requirements.txt

5. Install FluidSynth (macOS / Linux)

Windows users can skip this: the library ships in bin/.

# macOS
brew install fluid-synth
# Debian / Ubuntu
sudo apt install libfluidsynth3
# Fedora
sudo dnf install fluidsynth-libs
# Arch
sudo pacman -S fluidsynth
!
No piano sound? If Settings → Keyboard & Sound says FluidSynth is not installed, step 5 is missing: pyfluidsynth is there but the native library is not. Everything else works without it.

6. Run Pianove

python main.py

The first start opens the setup (language, name, experience, keyboard). Everything after that is saved and Pianove opens straight on Home.

Where your data lives

Pianove works entirely offline and keeps everything in one folder in your home directory:

PathWhat's in it
~/.pianove/storage.jsonSettings, progress, streaks and learning-path stars
~/.pianove/songs/Imported songs (a copy of each file plus an index)
~/.pianove/packages/Lessons and courses you made or imported

To start over, delete ~/.pianove/storage.json, run python reset_storage.py, or use Settings → Reset Onboarding to only repeat the setup.

Updating

git pull
pip install -r requirements.txt

Your progress and songs are outside the repository, so updating never touches them.

Running the tests

pip install pytest
python -m pytest tests -q

The tests run without a window, sound card or keyboard.

Building the app yourself

pip install pyinstaller
pyinstaller pianove.spec          # → dist/Pianove/  (dist/Pianove.app on macOS)

pianove.spec collects the lessons, fonts, the SoundFont and the FluidSynth library of the machine it runs on. .github/workflows/build.yml does this on Windows, macOS and Linux; pushing a tag such as v1.1.0 attaches the three builds to a GitHub release.
