Importing MusicXML

Supported formats, where to find files, and how to import them.

Supported Formats

Pianove accepts standard MusicXML in three container formats:

  • .xml — uncompressed MusicXML (plain text)
  • .musicxml — same as above, alternative extension
  • .mxl — compressed MusicXML (ZIP archive)

For multi-instrument scores only the first part is loaded. All other instruments are silently ignored.

How to Import

  1. Go to the Songs tab.
  2. Tap Import (the button in the header).
  3. A native OS file picker opens. Navigate to your MusicXML file and confirm.
  4. Pianove parses the file, extracts note data, and stores it in the local song library. The score renders immediately in the song detail view.
Import is non-destructive — the original file is not modified. Pianove stores a copy of the parsed data internally.

Song Library

All imported songs appear in the Songs tab as a scrollable list. Each entry shows the title, composer (from the MusicXML metadata), and difficulty rating.

Tap a song to open its detail screen, which shows the full score rendered by PyLute. From there you can start a practice session or delete the song.

What Is Not Supported

The following MusicXML features are silently skipped during import. Notes and rests in unsupported constructs are omitted without error.

  • Multiple voices on a single staff
  • Slurs
  • Repeat barlines, da capo, dal segno
  • Grace notes
  • Lyrics
  • Multi-instrument scores (only first part loaded)

Practice Mode

From the song detail screen, press Practice to start a sight-reading session. Before starting you can configure:

  • Clef — treble, bass, or both (grand staff)
  • Difficulty — controls which notes are included in the generated exercise
  • BPM — playback tempo

The session generates a randomised sequence of notes drawn from the song's pitch pool. Accuracy is recorded and added to your practice statistics.
