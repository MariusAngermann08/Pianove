Getting Started

System Requirements

What Pianove needs to run: Python packages, one native library, and something to play on.

Python 3.10+pygameFluidSynth

Python

Pianove needs Python 3.10 or newer (it uses X | Y type unions and other 3.10 syntax). It is developed and tested on current Python 3 releases, including 3.13.

Python packages

All of them are listed in requirements.txt:

pip install -r requirements.txt
PackageNeeded for
pygameThe window, drawing, fonts and input. PyLay and PyLute (bundled) build on it.
numpyThe microphone's note detection and a few calculations.
midoReading MIDI messages from your keyboard.
python-rtmidiThe MIDI backend mido uses to talk to USB devices.
pyfluidsynthThe Python side of the piano sound (see FluidSynth below).
sounddeviceRecording from the microphone. Only used by Hear My Piano.

The two libraries Pianove is built on, PyLute and PyLay, live in the repository and are picked up automatically; there is nothing extra to install for them.

FluidSynth

pyfluidsynth wraps libfluidsynth, a native library. Pianove needs it at start-up.

PlatformHow to get it
WindowsNothing to do: the DLLs ship in bin/ and are found automatically.
macOSbrew install fluid-synth
Debian / Ubuntusudo apt install libfluidsynth3
Fedorasudo dnf install fluidsynth-libs
Archsudo pacman -S fluidsynth
i
No sound device? If FluidSynth is installed but no audio output can be opened, Pianove still runs; it just stays silent.

Something to play on

  • A MIDI keyboard (recommended): any class-compliant USB MIDI keyboard or digital piano. Pianove asks for its lowest and highest key once, or recognises common models by name.
  • An acoustic piano and a microphone (beta): the built-in laptop or phone microphone is enough. See Hear My Piano.
  • Neither: you can still browse lessons, read scores and look around; playing needs one of the two.

Screen

Pianove is designed around a 1024 × 768 window and scales up to larger windows and full screen. The editors also have a layout for upright, phone-sized windows.
