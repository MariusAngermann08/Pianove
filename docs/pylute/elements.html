Staff, Bar, Note, Rest

The core hierarchy beneath Score. These objects are created automatically — this reference covers their public properties and the methods you may call directly.

Staff

A single staff — five horizontal lines and a list of bars. Instantiated by Score. Access via score.staffs[index].

PropertyTypeDescription
barslist[Bar]All bars on this staff, in order.
clef_typestr"treble" or "bass".
spaceintPixel distance between adjacent staff lines. Derived from the font size.
positionlist[int][x, y] pixel origin of this staff on the current surface.
lengthintStaff width in pixels (equals Score.length).
scoreScoreBack-reference to the owning Score.

Bar

A single measure. Holds events (notes and rests), tracks beat capacity, and handles beam grouping for eighth/sixteenth notes. Access via staff.bars[index].

PropertyTypeDescription
eventslist[Note | Rest]All note and rest events in chronological order.
indexintZero-based bar index within the staff.
timetuple[int, int]Local time signature (always equal to the score's time signature).
bar_start_xfloatPixel X of the bar's left barline within the system.
barspacefloatAllocated pixel width for this bar.
spaceAvailable() → float

Returns remaining beat capacity in this bar as a float (0.0 = full). One whole note = 1.0 unit of capacity. A 4/4 bar starts at 1.0 and decreases as events are added.

bar = score.staffs[0].bars[0]
print(bar.spaceAvailable())  # 1.0 (empty 4/4 bar)

score.addNote("half", "C4")
print(bar.spaceAvailable())  # 0.5

score.addNote("half", "E4")
print(bar.spaceAvailable())  # 0.0 (bar full)

Note

A single notated pitch. Instantiated by Score.addNote(). Access via bar.events.

class Note
Note(ntype="whole", pitch="C4", staff=None)
PropertyTypeDescription
typestrDuration type string, e.g. "quarter".
pitchstrScientific pitch notation, e.g. "F#4".
colortuple | NoneRGB color override for the notehead. None uses the default (black). Set to a color tuple to highlight a note: note.color = (220, 60, 60).
beamedboolSet to True by the bar renderer when this note is part of a beam group. Read-only in practice.
offsetfloatFractional horizontal position within the bar (0.0 = start, 1.0 = end). Computed by Bar.calculateMetrics().

Highlight a note

Set note.color to an RGB tuple to draw attention to specific notes — for example, highlighting the currently played key in Pianove.

bar = score.staffs[0].bars[0]
note = bar.events[0]
note.color = (52, 199, 89)   # green highlight
# Returns to normal on next frame if you reset it:
note.color = None

Rest

A rest symbol. Instantiated by Score.addRest(). Accepts the same duration types as Note. Rests have no pitch and render as standard music notation rest glyphs (half rest, quarter rest, etc.) using the Bravura font.

Rest(rtype="quarter", staff=None)
PropertyTypeDescription
typestrDuration type string.
offsetfloatHorizontal position within the bar (computed by Bar).

Clef, KeySignature, TimeSignature, Brace

These elements are created automatically by Score. You generally do not interact with them directly. They are listed here for completeness.

Clef

Clef(ctype="treble", staff=None)
# ctype: "treble" or "bass"
# Accessed via: score.clefs[staff_index]

KeySignature

KeySignature(accidentals=0, staff=None)
# accidentals: -7 (7 flats) to +7 (7 sharps). 0 = C major.
# Accessed via: score.key_signatures[staff_index]

The width property returns the pixel width of the rendered key signature — used internally to compute score.frontal_offset.

TimeSignature

TimeSignature(staff=None)
# Reads time from score.time
# Accessed via: score.time_signatures[staff_index]

Brace

Brace(staves: list[Staff], surface: pygame.Surface)
# Created automatically when staffs > 1
# Accessed via: score.brace

The brace renders the vertical curly bracket connecting two staves (standard for piano notation). Call score.brace.reset() if you update the staff layout manually.
